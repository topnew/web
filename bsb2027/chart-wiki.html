Tiny Chart JS

A small, dependency-free SVG chart library. Put simple CSV-style chart data inside a <div class="chart"> and the library renders it automatically.

One data format only: the first row contains headings, the first column contains categories/X-axis labels, and all remaining columns are numeric series.

1. Basic bar

<div class="chart">
Month,Qty;
Jan,120;
Feb,180;
Mar,150;
Apr,220
</div>
Month,Qty; Jan,120; Feb,180; Mar,150; Apr,220

2. Grouped bars

Add more value columns. Each column becomes a series.

<div class="chart">
Month,Tom,Sam,Peter;
Jan,120,180,90;
Feb,160,130,150;
Mar,190,210,170;
Apr,140,185,220
</div>
Month,Tom,Sam,Peter; Jan,120,180,90; Feb,160,130,150; Mar,190,210,170; Apr,140,185,220

3. Title, size and values

<div class="chart"
 data-title="Monthly Orders"
 data-w="700"
 data-h="320"
 data-val-show="1">
Month,Qty;
Jan,120;
Feb,180;
Mar,150;
Apr,220
</div>
Month,Qty; Jan,120; Feb,180; Mar,150; Apr,220

4. Axis titles and units

<div class="chart"
 data-x-title="Month"
 data-y-title="Sales"
 data-y-unit="$">
Month,Sales;
Jan,1200;
Feb,1800;
Mar,1500
</div>
Month,Sales; Jan,1200; Feb,1800; Mar,1500

5. Negative values

Month,Result; Jan,120; Feb,-80; Mar,150; Apr,-40; May,220

6. Stacked bars -- looks buggy

Use data-chart="stack". The old PHP name barV is also accepted.

<div class="chart" data-chart="stack">
Month,Tom,Sam,Peter;
Jan,120,180,90;
Feb,160,130,150;
Mar,190,210,170
</div>
Month,Tom,Sam,Peter; Jan,120,180,90; Feb,160,130,150; Mar,190,210,170

7. Stacked bars with negative values

Positive and negative stacks are accumulated separately.

Month,A,B,C; Jan,100,-40,30; Feb,-50,-30,120; Mar,80,60,-25

8. Line chart

<div class="chart" data-chart="line">
Month,Tom,Sam;
Jan,120,180;
Feb,160,130;
Mar,190,210
</div>
Month,Tom,Sam; Jan,120,180; Feb,160,130; Mar,190,210; Apr,140,185

9. Pie chart

Pie charts use the first numeric series.

<div class="chart" data-chart="pie" data-pie-pct="1">
Staff,Sales;
Tom,120;
Sam,180;
Peter,90
</div>
Staff,Sales; Tom,120; Sam,180; Peter,90

10. Donut

<div class="chart" data-chart="donut" data-pie-pct="1">
Staff,Sales;
Tom,120;
Sam,180;
Peter,90
</div>
Staff,Sales; Tom,120; Sam,180; Peter,90

11. X labels

data-x-angle rotates labels. data-x-skip explicitly skips labels; data-x-skip-max automatically reduces crowded labels.

Date,Orders; Sep 01,12; Sep 02,18; Sep 03,15; Sep 04,22; Sep 05,17; Sep 06,25; Sep 07,20; Sep 08,28; Sep 09,24; Sep 10,30; Sep 11,27; Sep 12,32

12. Legend

For multi-series charts the default legend is on the right. Set data-legend="T", B, L, R, or 0.

Month,Tom,Sam,Peter; Jan,120,180,90; Feb,160,130,150; Mar,190,210,170

13. Cumulative values

data-y-sum="1" converts each series to a running cumulative total before rendering.

Month,Orders; Jan,10; Feb,20; Mar,15; Apr,30

14. Group width

data-group-width="0.78" controls how much of each category slot the bars occupy.

Month,A,B,C; Jan,12,18,9; Feb,16,13,15; Mar,19,21,17

16. PHP output

The recommended boundary is simple: PHP prepares the data in the canonical chart format; JavaScript only renders it.

<div class="chart" data-title="Monthly Sales">
<?= chart_data($rows) ?>
</div>

The frontend therefore never needs to know whether the original data came from SQL, an API, PHP arrays, or another backend source.

Design rule

Good chart with zero configuration. Add attributes only when something needs to change.
